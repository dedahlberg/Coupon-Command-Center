# Coupon Command Center V2

Step 2 adds a source integration layer for:
- Coupons.com
- GrocerySmarts
- LOZO
- The Krazy Coupon Lady
- Manufacturer-direct programs
- Fetch Rewards

This build uses authorized link-outs instead of copying or generating coupon barcodes. Fetch offers are personalized by account, so the app opens Fetch for the user's actual offers.

Files:
- index.html
- sources.json
- offers.json
- vercel.json
